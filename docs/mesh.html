A mesh, run by its kernel

Each cell is a node someone owns. A row is a signal: it travels one hop per tick along a link, and only to a node whose owner may hold it. Every node applies the same fold to what it holds. Click a node to see its owner's queue and to preview an act before it is signed. The kernel is kernel.js, driven by the constitution's own tables; it replays the constitution's story exactly.
